# My Dress-Up Darling Fan Page

Una página fan en español LATAM inspirada en el anime **My Dress-Up Darling**.

El sitio presenta una experiencia visual sencilla y atractiva sobre la serie, con secciones dedicadas a la historia, los personajes, el cosplay y las razones por las que vale la pena verla.

## Qué incluye

- Portada visual con estética inspirada en el anime.
- Sección de historia y datos principales.
- Tarjetas de personajes con filtro interactivo.
- Apartado especial sobre el cosplay.
- Diseño adaptable para celular y escritorio.

## Tecnologías usadas

- HTML
- CSS
- JavaScript

## Vista previa

El archivo principal del sitio es:

```text
index.html
```
