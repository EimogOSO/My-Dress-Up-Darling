# My Dress-Up Darling Fan Page

Página fan en español LATAM sobre el anime *My Dress-Up Darling*.

## Publicación

Este proyecto es una página estática. Para publicarla con GitHub Pages:

1. Crear un repositorio público en GitHub.
2. Subir `index.html`, `.nojekyll` y este `README.md`.
3. Ir a `Settings > Pages`.
4. En `Build and deployment`, elegir `Deploy from a branch`.
5. Seleccionar la rama `main` y la carpeta `/root`.
6. Guardar.

Después de unos minutos, GitHub mostrará el enlace público de la página.
